

# ArcheoDB 🏺

**ArcheoDB** — это кроссплатформенное веб-приложение, предназначенное для автоматизации полевой регистрации, стратиграфического учета и каталогизации археологических находок. 

Система спроектирована с упором на мобильную адаптивность, что позволяет исследователям вносить данные в паспорт артефакта непосредственно на месте проведения раскопок со своих смартфонов.

## 🚀 Основной функционал

* **Ролевая модель и безопасность:** Разделение прав доступа. Гости могут просматривать каталог, авторизованные археологи — добавлять артефакты. Защита от редактирования чужих записей (IDOR) и безопасная авторизация через JWT-токены.
* **Каталогизация и смарт-фильтрация:** Быстрый поиск находок по автору, исторической эпохе, раскопу (местоположению) и текущему статусу (в поле, в фондах, на реставрации).
* **Медиа-галерея:** Поддержка загрузки главного фото (обложки) и множественной загрузки дополнительных ракурсов артефакта.
* **Адаптивный интерфейс:** UI/UX оптимизирован под мобильные устройства благодаря гибкой Flexbox-сетке и оптимизированной отдаче медиафайлов сервером.

## 🛠 Технологический стек

Проект полностью контейнеризирован.

**Backend:**
* Python 3.12
* Django & Django REST Framework (DRF)
* PostgreSQL (СУБД)
* JWT (Аутентификация)

**Frontend:**
* JavaScript / React (сборщик Vite)
* React Router DOM
* Axios

**Инфраструктура & Deploy:**
* Docker & Docker Compose
* Nginx (Reverse Proxy & раздача статики)
* Gunicorn (WSGI-сервер)
* Ngrok (Безопасное туннелирование для доступа из внешней сети)
